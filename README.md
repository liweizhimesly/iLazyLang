# Iazylang (or iL) - 一个轻量级解释器

这是一个用 Python 实现的自定义简单脚本语言 **Iazylang** 的解释器。它的语法直观，包含变量、字符串、基础运算和控制流，适合用于学习解释器原理或快速编写小型脚本。

## 语言特性

*   **简单易学**：指令集小巧，语法直观。
*   **两种变量**：支持整数 (`v0`, `v1`...) 和字符串。
*   **基础运算**：支持变量与数值之间的加 (`+`)、减 (`-`)、乘 (`*`)、整除 (`/`)。
*   **流程控制**：支持标签跳转 (`label:`)、无条件跳转 (`ngt`)、条件跳转 (`gto`)、条件判断 (`iff`)。
*   **输入输出**：支持控制台输入 (`inp`, `ips`) 和输出 (`out`, `otv`, `ovs`)。
*   **调试模式**：提供 `dbg` 和 `dbs` 指令，方便调试。

## 快速开始

### 运行环境
*   Python 3.x

### 如何使用
1.  将你的 Iazylang 代码保存到一个文件中，例如 `test.il`。
2.  确保 `main.py` 和你的 `.il` 文件在同一目录下。
3.  运行解释器：
    ```bash
    python main.py
    ```
    解释器会自动读取同目录下的 `pg.il` 文件并执行。要运行其他文件，请修改 `main.py` 中 `file_path` 变量的值。

## 基础语法示例

```il
// 设置变量并输出
set 0, 10
out v0=
otv 0

// 条件判断与跳转
iff 0>5
gto 5
out Condition is false
label:
out Jumped here!

// 字符串操作
sts 0,Hello
ips 1
ovs 0
out , 
ovs 1
